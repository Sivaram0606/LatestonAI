# Agent Spec: AI Daily Digest (`ai-daily-digest`)

## Overview
`ai-daily-digest` is a multi-agent AI intelligence briefing system built with Google Agent Development Kit (ADK) and paired with an interactive React + Vite web UI. Given any target date (`YYYY-MM-DD`), a coordinated team of specialist ADK agents fetches live data from popular AI APIs in parallel, deduplicates and ranks items by impact, and synthesizes a structured daily briefing across **Executive Summary**, **Papers**, **Models & Spaces**, **News**, and **Repos**.

## Architecture & Sub-Agents
The ADK `root_agent` is a `SequentialAgent` (`daily_digest_pipeline`) using `gemini-3.7-flash`:
1. **`parallel_api_collectors` (`ParallelAgent`)** — Executes specialized API researcher sub-agents concurrently, writing structured raw findings into isolated session state keys:
   - `papers_research_agent` (`output_key="raw_papers"`): Calls `fetch_hf_daily_papers(date)` (Hugging Face Daily Papers API) and `fetch_arxiv_ai_papers(date)` (arXiv `cs.AI`/`cs.LG`/`cs.CL` API) to gather and annotate top papers for the target date.
   - `models_spaces_agent` (`output_key="raw_models"`): Calls `fetch_hf_trending_models(date)` and `fetch_hf_trending_spaces(date)` (Hugging Face Hub API) to gather active/updated AI models and interactive Spaces.
   - `news_repos_agent` (`output_key="raw_news_repos"`): Calls `fetch_hackernews_ai_stories(date)` (HN Algolia API filtered by UTC day timestamps) and `fetch_github_ai_repos(date)` (GitHub REST Search API filtered by creation/push date) to gather community AI news and open-source repositories.
2. **`digest_synthesizer_agent` (`Agent` with `output_schema=DailyBriefing`)** — Reads `{raw_papers}`, `{raw_models}`, and `{raw_news_repos}` from session state, deduplicates cross-posted items, identifies overarching daily themes, and produces a strictly typed `DailyBriefing` JSON payload (`executive_summary`, `key_themes`, `highlights`, `papers`, `models`, `news`, `repos`).

## Example Use Cases
1. **Daily Briefing Generation**:
   - Input: `"Generate the AI daily briefing for 2025-02-14"` (or date selected in the React UI date picker).
   - Output: Structured `DailyBriefing` containing a 2–3 paragraph Executive Summary, key themes, and curated cards for Papers, Models & Spaces, News, and Repos with real URLs, authors/orgs, metrics (upvotes, downloads, points, stars), and concise "why it matters" takeaways.
2. **Historical Date Lookup**:
   - Input: User selects an earlier date (e.g., `2025-01-20`) in the UI date picker.
   - Output: Date-scoped papers from Hugging Face `/api/daily_papers?date=2025-01-20`, HN stories from that exact 24h UTC window, and GitHub AI repos created/active on that date, summarized for that day.

## Tools Required
All tools are Python `FunctionTool` callables in `app/tools.py` using public, unauthenticated REST endpoints (`aiohttp` / `urllib`) with timeouts and graceful fallback handling:
- `fetch_hf_daily_papers(target_date: str) -> dict`: `GET https://huggingface.co/api/daily_papers?date={target_date}` (falls back to latest available date if weekend/holiday has 0 papers, noting the date).
- `fetch_arxiv_ai_papers(target_date: str) -> dict`: `GET https://export.arxiv.org/api/query` scoped to `cat:cs.AI OR cat:cs.LG OR cat:cs.CL` around `target_date`.
- `fetch_hf_trending_models(target_date: str) -> dict`: `GET https://huggingface.co/api/models?sort=likes7d&direction=-1&limit=15` (plus date-filtered recent models).
- `fetch_hf_trending_spaces(target_date: str) -> dict`: `GET https://huggingface.co/api/spaces?sort=likes7d&direction=-1&limit=10`.
- `fetch_hackernews_ai_stories(target_date: str) -> dict`: `GET https://hn.algolia.com/api/v1/search` with `numericFilters=created_at_i>={start_ts},created_at_i<{end_ts}` and AI query terms.
- `fetch_github_ai_repos(target_date: str) -> dict`: `GET https://api.github.com/search/repositories` scoped to AI/LLM/agent topics active or created on `target_date` (optional `GITHUB_TOKEN` header if set for higher rate limits).

## Constraints & Safety Rules
- **Strict Grounding (Zero Hallucinated Links)**: Every paper, model, space, news story, and repository URL in the output MUST originate verbatim from tool outputs. Never invent URLs, arXiv IDs, repo names, or metric counts.
- **Date Fidelity**: Validate `target_date` as `YYYY-MM-DD`. Note clearly when a source (such as Hugging Face Daily Papers on weekends or future dates) has no publications for that exact date rather than fabricating entries.
- **Read-Only External Access**: Tools perform strictly read-only `GET` requests with a 12-second timeout and bounded response size.
- **Code Preservation**: Preserve scaffolded `MODEL = "gemini-3.7-flash"`, `app/__init__.py` (`App(name="app")`), and `app/fast_api_app.py`. Serve UI-specific REST endpoints via a companion `server.py` module without mutating generated runtime files.

## Assumptions
- Public unauthenticated AI APIs (Hugging Face Hub API, arXiv API, Hacker News Algolia API, GitHub public Search API) are used so no third-party API keys are required out of the box.
- Vertex AI (`GOOGLE_GENAI_USE_VERTEXAI=true`, `GOOGLE_CLOUD_LOCATION=global`) is the primary LLM backend, with automatic support for `GEMINI_API_KEY` if configured in `.env`.

## Success Criteria
1. All unit tests (`uv run pytest tests/unit`) pass with 100% success on tool parsing, date window calculation, and schema validation.
2. `agents-cli eval run` achieves >= 0.8 score on response quality and tool trajectory across sample daily briefing prompts.
3. Backend `/api/digest?date=YYYY-MM-DD` returns valid `DailyBriefing` JSON with populated Executive Summary, Papers, Models, News, and Repos sections and live agent stage telemetry.
4. React + Vite UI renders date selector, Executive Summary, category tabs/cards (Papers, Models, News, Repos), live agent workflow progress, dark/light theme toggle, and clickable external links cleanly across desktop and mobile viewports.
